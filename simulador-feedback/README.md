# Simulador de Feedback (SBI)

Este diretório descreve uma simulação do método SBI (Situação, Comportamento e Impacto)
para apoiar líderes na construção de feedbacks claros e objetivos com apoio de IA.

## Estrutura de prompt sugerida
1. **Situação**: contexto específico do evento.
2. **Comportamento**: ação observável da pessoa colaboradora.
3. **Impacto**: efeito no time, entrega ou negócio.
4. **Próximo passo**: acordo de melhoria com linguagem construtiva.

## Exemplo rápido
- Situação: "Na reunião de planejamento de segunda-feira..."
- Comportamento: "...houve interrupções recorrentes da fala do time..."
- Impacto: "...o grupo não conseguiu fechar prioridades no tempo previsto."
