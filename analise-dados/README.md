# Análise de Dados (People Analytics)

Esta pasta contém um script em Python com dados fictícios para apoiar análises de turnover.

## Arquivos
- `analise_people_analytics.py`: gera análises básicas e gráficos.
- `grafico_correlacoes.png`: matriz de correlação entre variáveis de RH.
- `grafico_turnover_motivos.png`: distribuição dos principais motivos de saída.

## Como executar
```bash
python analise_people_analytics.py
```

O script usa `pandas` e `matplotlib` para gerar os gráficos localmente.
